Off — everything reads Garage's cached snapshots, which trail by 8–12 minutes while a car is charging and much longer once it is parked. This is how the dashboard has always worked.
On — every monitored vehicle is read in real time, so a completion is caught in seconds instead of minutes. Cookie: in Garage press F12 → Network, click any request, find Request Headers, and copy the entire Cookie: value. This is your full Garage identity — it is stored in .garage.json on this machine only, never sent back to this page, and never committed. It expires on Garage's own schedule; when it does, live read switches itself off and says so.
